# Rigid Body Simulation

> Blender 骨骼物理辅助插件 · **v1.1.3**
>
> 将骨骼链转换为可编辑的刚体模拟，支持多链批量创建、骨骼碰撞体、IK 绑定、阻尼跟随与局部旋转传递。

![骨骼刚体模拟效果](images/所有刚体链的模拟效果.gif)

## 功能一览

- 将选中的骨骼链生成为刚体代理与弹簧关节；支持同时识别并创建多条链。
- 通过骨骼碰撞体，让物理链与身体、四肢等部位产生碰撞。
- 创建连续骨骼链 IK，或将已有 IK 控制骨与解算链作为两个孤岛绑定。
- 添加阻尼跟随、重置物理代理位置、控制代理显示，并管理生成内容。
- 对绑定骨骼链的细分曲面网格切换极限表面预览；为手指等骨骼添加局部 X 轴旋转传递。

## 版本与安装

| 安装包 | 最低 Blender 版本 | 适用场景 |
| --- | --- | --- |
| `4.2` 版本 | Blender 4.2 | Blender 4.2 及更新的 4.x 环境 |
| `5.2` 版本 | Blender 5.2 | Blender 5.2 及更新版本 |

两个版本的功能模块保持一致，主要区别是 Blender API 兼容目标。请根据正在使用的 Blender 版本，安装对应目录或发布包中的版本，不要把 4.2 和 5.2 的插件文件混装。

1. 在 GitHub Releases 下载对应 Blender 版本的插件包。
2. Blender 4.2 使用标注为 **4.2** 的包；Blender 5.2 使用标注为 **5.2** 的包。
3. Blender 4.x 扩展包可在 **编辑 > 偏好设置 > 扩展 > 从磁盘安装** 中安装；传统 Add-on 包则在 **编辑 > 偏好设置 > 插件 > 安装...** 中安装。
4. 启用插件，选择一个 Armature（骨架）。在 3D 视图按 `N` 打开侧栏，进入 **刚体模拟** 面板。

创建刚体链、碰撞体、IK 和旋转传递时，需要在 **姿态模式（Pose Mode）** 操作。面板也会在对象模式和编辑模式显示，便于查看和管理设置。

## 一、刚体骨骼链

刚体骨骼链适用于头发、飘带、裙摆和衣物等需要随角色运动、同时保留动态摆动的骨骼结构。插件在选中骨骼上创建刚体代理和链间物理关节；根骨骼继续接受动画驱动。

### 单链创建

1. 进入姿态模式，选择一条连续的父子骨骼链。
2. 将链根设为活动骨骼，根骨骼本身不生成动态刚体。
3. 选择预设或调整刚体半径、长度比例、质量、阻尼、根部跟随强度和弹簧参数。
4. 点击 **创建骨骼链刚体**，播放时间轴查看模拟。

### 多链与裙摆批量创建

插件保留原有的“活动根骨骼 + 一条连续链”操作，同时也会根据所选骨骼自动识别多条链：

- 同时选择多条链的根骨骼，可批量创建多条刚体链。
- 选择来自不同孤岛链条的骨骼时，插件会反查各自的链根并分别创建。
- 裙摆等环形或分片结构，可选择所有链根一次性创建；每条链独立生成代理和约束。

### 预设与参数

面板提供 **默认、裙摆、头发、飘带** 四个预设。可以在选中预设后继续调整参数；在名称框填写名称并点击 **添加**，可将当前参数保存到场景。选中自定义预设后可将其删除；名称留空时可保存对当前预设的参数调整。

#### 头发

头发预设使用较大的代理半径与质量，适合作为较长发束的起始值。若快速动作中出现持续摆动或抖动，可逐步提高阻尼。

#### 飘带

飘带预设的代理半径与质量较小、弹簧较柔，适用于窄长带状结构。若回弹过强，可增加弹簧阻尼或降低质量。

#### 裙摆

裙摆预设提供中等质量与稳定的根部跟随，适合多条裙摆链批量创建。可根据裙摆层数和相邻链间距调整代理半径及长度比例。

| 预设 | 半径 | 长度比例 | 质量 | 线性阻尼 | 角阻尼 | 根部跟随 | 弹簧刚度 | 弹簧阻尼 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 默认 | 0.01 | 0.85 | 0.50 | 0.85 | 0.45 | 0.50 | 10 | 7.5 |
| 裙摆 | 0.01 | 0.85 | 0.50 | 0.85 | 0.45 | 0.50 | 10 | 7.5 |
| 头发 | 0.02 | 0.80 | 1.50 | 0.95 | 0.55 | 0.50 | 15 | 10 |
| 飘带 | 0.005 | 0.85 | 0.25 | 0.75 | 0.65 | 0.50 | 7.5 | 5 |

半径与长度比例决定代理覆盖范围；质量影响惯性；线性阻尼和角阻尼抑制运动；根部跟随和弹簧参数影响链条跟随、回弹与稳定性。弹簧刚度、阻尼使用面板的 `1–100` 显示范围，创建物理关节时会换算为内部值。

### 根部跟随、重置与烘焙预览

- **阻尼跟随**：对选中的骨骼创建或覆盖阻尼跟随约束。目标代理根据第一根子骨骼的刚体自动指定；没有对应子骨骼代理时会跳过。
- **重置刚体位置**：把当前骨架生成的刚体代理放回对应骨骼中心，并保留链条关节和根部跟随关系。可用于代理偏离骨架后的校正。
- **优化烘焙预览**：切换当前骨架绑定网格细分曲面修改器的“使用极限表面”选项，以便比较烘焙模拟的网格预览效果。该按钮不会替代刚体缓存的清理或重新烘焙。
- **运动中旋转骨骼**：播放模拟时调整上游骨骼姿态，刚体链会随锚点更新后继续模拟。

如果旧缓存导致代理停留在过期位置，可先检查刚体世界的缓存状态并清理或重新烘焙；需要重新对齐代理时再使用 **重置刚体位置**。

## 二、骨骼碰撞体

骨骼碰撞体是跟随骨骼的被动障碍物，可用于躯干、手臂、腿部等部位，阻挡头发、衣物和裙摆刚体。可一次选中多根骨骼并批量添加，支持 **盒体、胶囊、球体** 三种形状。重复为同一骨骼添加时会替换该骨骼对应的插件碰撞体。

1. 在姿态模式选择需要参与碰撞的骨骼。
2. 调整碰撞体半径并选择形状。
3. 点击 **添加碰撞体**，播放刚体链模拟检查碰撞效果。

| 添加骨骼碰撞体 | 碰撞模拟效果 |
| --- | --- |
| ![创建骨骼碰撞体](images/创建骨骼碰撞体.gif) | ![刚体链与骨骼碰撞体交互](images/刚体链与骨骼碰撞体的碰撞交互效果.jpg) |

**显示/隐藏**仅切换碰撞体代理的视图与渲染显示，隐藏时碰撞仍然有效。使用 **删除当前骨骼碰撞体** 移除选中骨骼的碰撞体，或在“删除所有”区域删除当前骨架生成的全部碰撞体。

## 三、IK 绑定

插件支持 Blender 原生 IK 约束，并提供可移动的自定义控制形状。面板的 **IK 自定义物体缩放** 使用同一个数值控制 X、Y、Z 三轴大小。

### 连续链模式

选择连续的 IK 骨骼链并将末端骨骼设为活动项，点击 **创建 IK 骨骼链**。插件会创建 IK 控制骨和控制形状，并为解算链添加 IK 约束。

### 双孤岛模式

如果骨架已有独立 IK 控制骨，可以用两个互不相连的选择孤岛绑定：

1. 选择现成的 IK 控制骨并将它设为活动骨骼；该孤岛必须只有这一根骨骼。
2. 同时选择另一条连续、无分支的待解算骨骼链。
3. 点击 **创建 IK 骨骼链**。

插件会复用活动骨骼作为 IK 目标，不会再创建控制骨；另一孤岛的末端骨骼接收 IK 约束，链长按所选链条骨骼数确定。多于两个孤岛、控制孤岛含多根骨骼或解算链分叉时会拒绝创建。

![创建 IK 骨骼链](images/IK骨骼链的创建.gif)

使用 **删除当前骨骼 IK** 可从相关控制骨或 IK 骨骼上删除插件创建的绑定；**删除所有 IK 骨骼**可清理当前骨架上的插件 IK 内容。

## 四、旋转传递

旋转传递适合手指和需要沿链继承父骨骼局部 X 轴旋转的辅助骨骼。选择连续骨骼链，并将旋转来源骨骼设为活动项，点击 **添加**。插件会为后续骨骼添加局部空间的 `Copy Rotation` 约束，只传递 X 轴旋转。重复添加只替换插件创建的旋转传递约束，不会删除其他自定义约束。

**删除**会移除选中骨骼上的旋转传递；**删除所有旋转传递**会清除当前骨架上的插件约束。

## 显示、删除与注意事项

- **代理显示/隐藏**只控制当前骨架刚体代理的显示，物理模拟仍继续运行；碰撞体显示按钮行为相同。
- **删除选中骨骼刚体**只清理选中骨骼关联的生成代理和关节；“删除所有”区域可按模块清理整副骨架的刚体链、碰撞体、IK 或旋转传递。
- 删除操作按模块分别清理插件生成内容，不会把其他模块的对象混在一起删除。
- 创建链条时请确保所选骨骼关系清晰。单链要求连续父子关系；多链选择会依据已选根骨骼或子骨骼识别各自链条。
- 遇到穿插或抖动时，检查碰撞体半径、代理长度、质量和阻尼；薄片结构可尝试缩小半径并调整弹簧参数。
- 刚体链代理偏移或缓存过期时，先检查缓存，再按需清理/重新烘焙并重置代理位置。
- 物理结果取决于骨架层级、场景尺度、刚体世界设置和缓存状态；建议先用短链确认参数，再应用到完整角色。
