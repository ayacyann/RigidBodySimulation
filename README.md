# Rigid Body Simulation

Blender 骨骼物理辅助插件（v1.1.0）。在姿态模式下，从 3D 视图右侧的 **刚体模拟** 面板使用。

## 安装

需要 Blender 4.2 或更高版本。GitHub 仓库只保存源代码，安装包位于 GitHub Releases：

1. 下载 `RigidBodySimulation-<版本>-extension.zip`（Blender 4.x 推荐）或 `RigidBodySimulation-<版本>-addon.zip`。
2. 扩展包：打开 **编辑 > 偏好设置 > 扩展 > 从磁盘安装**。
3. Add-on 包：打开 **编辑 > 偏好设置 > 插件 > 安装...**。
4. 启用插件，选择骨架并切换到 **姿态模式**，按 `N` 打开面板。

也可以从源码安装：将 `RigidBodySimulation` 文件夹复制到 Blender 用户目录的 `scripts/addons/` 下，然后在偏好设置中启用插件。不要重复嵌套同名文件夹。

## 使用

### 骨骼链刚体

选择一条连续骨骼链，将要作为根部的骨骼设为活动骨骼。选择裙摆、头发或飘带预设，或调整半径、质量、阻尼和跟随参数，点击 **创建骨骼链刚体**。根骨骼保持动画控制，其余骨骼参与物理模拟。

### 骨骼碰撞体

选择腿部、身体等需要阻挡刚体的骨骼，设置半径和盒体、胶囊或球体形状，点击 **添加碰撞体**。碰撞体会跟随骨骼和 IK 移动，可用 **显示/隐藏** 查看代理。

### IK 骨骼链

选择连续骨骼并将末端设为活动骨骼，点击 **创建 IK 骨骼链**。生成的长方体控制骨骼可直接移动，用于反向控制骨骼链。

### 旋转传递

选择一根骨骼或一条骨骼链，点击 **添加**，即可让骨骼复制父骨骼的局部 X 轴旋转。需要清除时使用 **删除** 或底部的 **删除所有旋转传递**。

### 删除与显示

各模块的“删除当前/选中”按钮只处理选中的内容；底部 **删除所有** 区域可以分别删除刚体链、碰撞体、IK 骨骼和旋转传递。显示/隐藏只影响视图，不会停用物理模拟。

界面会跟随 Blender 语言设置：简体中文和繁体中文显示中文，其他语言显示英文。
